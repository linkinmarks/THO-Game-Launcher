## Có gì trong THO?

- Quản lý game và ứng dụng trong hai tab riêng, tìm kiếm và mở nhanh từ một nơi.
- Tự phát hiện game đã cài từ Steam, Epic Games và GOG; hỗ trợ quét thư mục hoặc thêm thủ công.
- Tìm ứng dụng người dùng cài đặt, lọc các công cụ hệ thống Windows đã nhận diện; xem trước và chọn kết quả trước khi nhập.
- Gợi ý game từ thư viện, ưu tiên những mục yêu thích.
- Theo dõi thời gian chơi game, giúp bạn bớt phụ thuộc vào hàng loạt shortcut trên desktop.

## Cài đặt và bắt đầu

1. Tải file **THO-Game-Launcher-1.1.3-Setup.exe** ở trên. Nếu tải ZIP, giải nén rồi mở **Setup.exe** bên trong.
2. Chạy bộ cài. Thư mục mặc định là `C:\Program Files (x86)\THO Game Launcher`.
3. Mở THO, chọn tab **Game** hoặc **Ứng dụng**, bấm **+ → Tìm game/ứng dụng trên máy**.
4. Duyệt danh sách, chọn những mục muốn thêm rồi bắt đầu sử dụng.

Để cập nhật bản đang dùng: chọn **bánh răng → Cập nhật ứng dụng**, sau đó chọn file Setup mới.

Yêu cầu: Windows 64-bit và .NET Framework 4.8. Bộ cài không kèm game hoặc ứng dụng khác.

## Lưu ý khi trải nghiệm Beta

- Thời gian chơi chỉ được ghi nhận khi mở game qua THO, giữ THO chạy (có thể thu nhỏ) và nhận diện được tiến trình game. Xem tại **thẻ game → CÀI ĐẶT → Thời gian chơi**, hoặc rê chuột lên tên game.
- Bản 1.1.3 chưa ghi thời gian sử dụng ứng dụng và không nhập số giờ chơi cũ từ cửa hàng.
- Một số game, ứng dụng Store hoặc shortcut đặc biệt có thể cần thêm thủ công. THO không thay thế tài khoản hay yêu cầu khởi chạy của cửa hàng game.
- Gỡ cài đặt bằng **Uninstall.exe** trong thư mục cài hoặc mục ứng dụng đã cài của Windows. Sau xác nhận, dữ liệu thư viện THO của người dùng hiện tại sẽ bị xóa; các game bên ngoài vẫn được giữ lại.
