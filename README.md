## Mới trong Closed Beta 1.2.0 — 21/11/2026

- Widget mini bo góc trên desktop tự hiển thị game đã đánh dấu yêu thích, 2 game mỗi trang; bấm ảnh bìa để mở game.
- Khi có hơn 2 game yêu thích, tự chuyển trang mỗi 6 giây. Tạm dừng lúc rê chuột, kéo widget hoặc mở hộp thoại cài đặt; có nút chuyển trang thủ công.
- Widget không có nút riêng trên taskbar. Đóng cửa sổ thư viện vẫn giữ widget hoạt động; đóng bằng nút X hoặc tắt trong cài đặt.
- Có tùy chọn khởi động widget cùng Windows (mặc định tắt) và chế độ **Chỉ hiện widget**.
- Sửa vị trí/kích thước cửa sổ theo vùng làm việc và DPI để thanh tiêu đề, nút **+** nằm trong màn hình khi dùng màn hình nhỏ.
- Tiếp tục có thời gian chơi cạnh chấm trạng thái trên ảnh bìa (`45m`, `2h`, `12h 30m`) và menu cài đặt có icon kèm chữ.

## Có gì trong THO?

- Quản lý game và ứng dụng trong hai tab riêng, tìm kiếm và mở nhanh từ một nơi.
- Tự phát hiện game đã cài từ Steam, Epic Games và GOG; hỗ trợ quét thư mục hoặc thêm thủ công.
- Tìm ứng dụng người dùng cài đặt, lọc các công cụ hệ thống Windows đã nhận diện; xem trước và chọn kết quả trước khi nhập.
- Gợi ý game từ thư viện, ưu tiên những mục yêu thích.
- Theo dõi thời gian chơi game, giúp bạn bớt phụ thuộc vào hàng loạt shortcut trên desktop.

## Cài đặt và bắt đầu

1. Tải file **THO-Game-Launcher-1.2.0-Setup.exe** ở trên. Nếu tải ZIP, giải nén rồi mở **Setup.exe** bên trong.
2. Chạy bộ cài. Thư mục mặc định là `C:\Program Files (x86)\THO Game Launcher`.
3. Mở THO, chọn tab **Game** hoặc **Ứng dụng**, bấm **+ → Tìm game/ứng dụng trên máy**.
4. Duyệt danh sách, chọn những mục muốn thêm rồi bắt đầu sử dụng.

Để cập nhật bản đang dùng: chọn **bánh răng → Cập nhật ứng dụng**, sau đó chọn file Setup mới.

Yêu cầu: Windows 10/11 64-bit và .NET Framework 4.8. Bộ cài không kèm game hoặc ứng dụng khác.

## Sử dụng widget

1. Đánh dấu yêu thích những game muốn hiện trong widget từ menu của từng game.
2. Bật widget trong cài đặt THO. Danh sách tự đồng bộ từ mục yêu thích; không cần chọn lại game.
3. Bật tùy chọn khởi động cùng Windows nếu muốn widget xuất hiện sau khi đăng nhập. Tùy chọn này chỉ mở widget, không tự chạy game.
4. Đóng cửa sổ thư viện để tiếp tục dùng widget; bấm **X** trên widget hoặc tắt trong cài đặt khi muốn dừng.

## Lưu ý khi trải nghiệm Beta

- Thời gian chơi chỉ được ghi nhận khi mở game qua THO, giữ THO hoặc widget chạy và nhận diện được tiến trình game. Số giờ/phút hiển thị ngay cạnh chấm trạng thái trên ảnh bìa; xem chi tiết tại **thẻ game → CÀI ĐẶT → Thời gian chơi**, hoặc rê chuột lên tên game.
- Bản 1.2.0 chưa ghi thời gian sử dụng ứng dụng và không nhập số giờ chơi cũ từ cửa hàng.
- Một số game, ứng dụng Store hoặc shortcut đặc biệt có thể cần thêm thủ công. THO không thay thế tài khoản hay yêu cầu khởi chạy của cửa hàng game.
- Gỡ cài đặt bằng **Uninstall.exe** trong thư mục cài hoặc mục ứng dụng đã cài của Windows. Sau xác nhận, dữ liệu thư viện THO của người dùng hiện tại sẽ bị xóa; các game bên ngoài vẫn được giữ lại.
